Overlay Widget Script + Overlay Widget Design

Draw over everything.

Android can't draw anywhere on screen the way Windows can. OWS and OWD fix that as equal halves: OWS is the logic, OWD is the look. Together they put widgets above every app, on any host, with no setup.

How it works

A layer above the layer above.

Normal apps live inside their own window. An OWS overlay is drawn by the system compositor on top of every window, so it stays visible while you switch apps, games or desktops.

Two languages, one system
Logic in OWS. Looks in OWD.




OWS
Overlay Widget Script
The logic. Events, state and behaviour: what a widget does when you tap it, hold it, or something happens on the device.


OWD
Overlay Widget Design
The design. Shape, size, colour, images and GIFs, kept separate from the logic so you can restyle without touching behaviour.


Shape-shifting
A widget changes its form when an event triggers it: circle to card to pill.


Images and GIFs
Overlays can show still images and animated GIFs, not just flat shapes.


Widgets from code
Create widgets through programming, using the device's native wallpaper engine.


Overlay permission
On Android it uses the system overlay permission to give you the "draw anywhere" power Windows has.







Language features
Everything it does.







Host manager
Invisible. Automatic. Always right.


You never call it. A built-in host manager works in the background, works out where your script is running, and adapts. It also sees through proot and fake or spoofed hosts and handles them correctly instead of being fooled.

Download & run


Get the CLI from GitHub, then:


    

  1. Download the release from GitHub → Abhi13-coder/OWS-OWD
    2. 

  2. Unzip — you get ows (and ows.bat on Windows)
    3. 

  3. Put your .ows + matching .owd in the same folder
    4. 

  4. Headless: ows run main.ows
    5. 

  5. Overlay: ows run overlay main.ows
    6. 



Omit attach and the runtime auto-picks a sibling .owd. Explicit attach always wins when present.

Roadmap


Where it’s going.


v1.0 is the working core. Everything after builds on the same OWS + OWD split.







v1.0 · current


Core overlays


Shape-shifting, button clicks, class events, animations (inside widget + overlay itself), online API, classes. Headless CLI + overlay path.






v1.1


Media, wallpaper & packages


Images & GIFs, audio, wallpaper / lock-screen widgets, ows install / owd install, import, user-defined packages.






v1.2


Exceptions + video


Built-in exception handling (Java/Kotlin style) and video support inside overlays.






v1.3


PiP & visual assistants


Picture-in-picture apps, official guides for visual assistants (VTuber-style / cute anime always-on characters), and a ready assistant package.






v1.4


Offline AI


Official offline AI pipeline. Lightweight, RAM-tiered ML libraries and models (from ~250 MB floor upward).






v1.5


Data, sensors & HUDs


Official database management, sensor-based radar-style visuals, and working HUDs.
