OWS Language Reference

Full syntax for OWS (Overlay Widget Script — logic) and OWD (Overlay Widget Design — layout/style). OWS handles events, state and behaviour; OWD handles what the widget looks like. A widget is always two files working together.

File structure

An OWS file attaches to a sibling OWD file that defines the widget tree it controls.

attach src = "widget.owd"
number count = 0

Omit attach and the runtime auto-picks a sibling .owd file with a matching name. An explicit attach always wins when present.

Variables & types

number count = 0
string statusText = "Tap GET or POST"
var payload = { "msg": "hello from OWS", "n": 42 }

Functions

fun formatCount(n) {
    return "Count: " + str(n)
}

Events

OWS is event-driven. A when block runs whenever the named event fires — a tap, a class event, or a completed API call.

when Plus.clicked {
    count = count + 1
    Counter.txt = formatCount(count)
}

Control flow

if count < 0 {
    count = 0
}

HTTP / API calls

Async calls run on a background thread so the overlay UI stays responsive. Handle the result in a matching when block.

when Fetch.clicked {
    http.get_async("https://httpbin.org/get", "onGet")
}

when onGet {
    var res = http.result("onGet")
    if res.ok {
        Status.txt = "OK " + str(res.status)
    } else {
        Status.txt = "Error"
    }
}

POST works the same way with http.post_async(url, payload, "eventName"). See the full working example on the samples page.

OWD — widget design

OWD is declarative: a widget tree of nested elements with layout and style properties. No behaviour is mixed in — that stays in OWS.

Widget CounterRoot {
    width: 260
    height: 160
    radius: 24
    background: "#151515"

    Text Counter {
        txt: "Count: 0"
        size: 28
        x: 16
        y: 24
    }

    Button Plus {
        txt: "+"
        x: 190
        y: 90
        width: 50
        height: 48
        radius: 12
        background: "#1E88E5"
    }
}

Common OWD properties

PropertyApplies toDescription
width / heightany elementSize in pixels
x / yany elementPosition within parent
radiusany elementCorner radius
backgroundany elementHex color
txtText, ButtonDisplayed text (bindable from OWS)
sizeTextFont size

Host manager

A built-in host manager detects where the script is running — Android (via the overlay permission), Linux, Windows, virtual machines, and even proot or spoofed/fake hosts — and adapts automatically. It's invisible: you never call it directly.

Running a script

# Headless — compiles and registers handlers, no GUI
ows run main.ows

# Requests a real overlay through the Host Manager
ows run overlay main.ows
