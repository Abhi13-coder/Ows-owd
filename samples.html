Samples

Two runnable OWS + OWD projects. Each has a .ows logic file and a matching .owd design file — copy both into a folder and run with the CLI (setup guide here).

1. Counter — the basics

A minimal overlay widget: two buttons, one text field, incrementing/decrementing state. Good first widget to understand the OWS/OWD split.

counter/main.ows

attach src = "widget.owd"
number count = 0

fun formatCount(n) {
    return "Count: " + str(n)
}

when Plus.clicked {
    count = count + 1
    Counter.txt = formatCount(count)
}

when Minus.clicked {
    count = count - 1
    if count < 0 { count = 0 }
    Counter.txt = formatCount(count)
}

2. API Demo — async HTTP

Shows non-blocking GET and POST requests from inside an overlay. The request runs on a background thread; the result comes back through a named event so the widget's UI never freezes.

api_demo/main.ows

attach src = "widget.owd"
string statusText = "Tap GET or POST"

when Fetch.clicked {
    Status.txt = "Loading (async)..."
    Body.txt = ""
    http.get_async("https://httpbin.org/get", "onGet")
}

when onGet {
    var res = http.result("onGet")
    if res.ok {
        Status.txt = "OK " + str(res.status)
        var origin = res.json["origin"]
        Body.txt = "origin=" + str(origin)
    } else {
        Status.txt = "Error"
        Body.txt = str(res.error)
    }
}

when PostBtn.clicked {
    Status.txt = "Posting (async)..."
    var payload = { "msg": "hello from OWS", "n": 42 }
    http.post_async("https://httpbin.org/post", payload, "onPost")
}

when onPost {
    var res = http.result("onPost")
    if res.ok {
        Status.txt = "Posted " + str(res.status)
        Body.txt = str(res.json["json"])
    } else {
        Status.txt = "Post failed"
        Body.txt = str(res.error)
    }
}
