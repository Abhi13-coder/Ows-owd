Get Started

Five steps to your first always-on-top overlay widget, on Android, Linux, or Windows.

1 Download the CLI

Grab the CLI package from GitHub Releases.

2 Unzip

You'll have:

ows          # Unix / Linux / macOS
ows.bat      # Windows

3 Write a widget

Create two files with matching names in the same folder — one .ows (logic), one .owd (design). See the samples page for full working examples, or the language reference for full syntax.

main.ows
main.owd

4 Run headless

Compiles the script and registers handlers, no GUI:

ows run main.ows

5 Run as a real overlay

Requests an actual always-on-top overlay through the Host Manager. On Android this needs the "Display over other apps" permission — the runtime prompts for it automatically.

ows run overlay main.ows

That's it — no build step, no app scaffolding. See full samples →
